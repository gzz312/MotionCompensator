# 本地数据与隐私

**中文** | [English](en/PRIVACY.md)

软件不提供自动上传、账号登录、云端分析或自动更新功能。当前捕获与运动分析在本机完成。

- 设置保存在当前用户的`HKCU\Software\MotionCompensator`，使用PreferencesV4并兼容旧格式。
- 只在用户勾选“日志”后写入EXE旁`logs/`，每次启动默认关闭。取消勾选后停止并保留已有文件。
- 日志记录连接目标/进程信息、时间戳、帧率、输入事件统计/运动控制状态、光流与补偿向量等诊断信息；不记录任意键盘输入文字。日志不是匿名数据，分享前应检查。
- 正常日志开关不保存游戏截图。开发者显式使用`--flow-debug`并启用诊断记录时可能保存有限灰度帧，不要把它当作普通用户日志模式。
- CSV轮转为单文件10MiB、合计100MiB、最多20份，只管理当前目录的session-*.csv常规文件；不递归清理其他目录。
- 工具不读取游戏进程内存，不注入DLL，不拦截或修改游戏输入流。外部叠加层与只读输入观察不代表对所有游戏规则作保证。

分享反馈时优先提供版本、复现步骤和必要的日志片段，不要直接上传包含其他个人内容的整个工作目录。
