# 已知问题与预览边界

**中文** | [English](en/KNOWN-ISSUES.md)

当前为预览版。兼容性与视觉舒适度因游戏和设备而异，尚未验证普遍的晕动缓解效果。

- 主要面向第一人称游戏。第三人称驾驶、大面积静止前景及单调背景可能导致运动漏检、估速偏大或点阵不连续；这些场景尚未专门优化。
- 分析以30次/秒为目标，不等于游戏FPS。更短帧对不能恢复已经模糊的细节，低纹理下的微小匹配误差也可能放大成速度抖动。
- 独占全屏可能盖住外部浮层，建议无边框或窗口模式；不同游戏/反作弊策略仍需自行核对，不能承诺所有游戏允许或兼容。
- 低纹理、强运动模糊、切镜、手持武器/HUD遮挡可能降低光流有效性。输入预测表示动作意图，不等同于跳跃、顶墙、驾驶、过场等真实角色状态。
- 动态模式不会自动切成静态；没有可靠观测时保留输入预测/动态处理路径，可能显示等待或观测不足提示。
- 部分显示环境下仍可能出现控件闪烁或缩放异常。反馈时请附上主题、显示缩放比例和复现步骤。
- 多屏与所有DPI比例尚未全面验证；最大化入口保持关闭。
- Tab焦点导航未完整实现，当前以鼠标操作为主。
- 多个版本同时运行会争用快捷键，退出其他版本再测试。快捷键冲突会提示并重试。
- 日志需写入EXE旁目录。目录不可写时记录会失败并提示，不会自动改写到其他目录。
- OpenCV灰度后端已实现；NVIDIA光流、RGB光流、AI分割/预测和官方游戏遥测仍未接入。它们不是本包已实现功能。
- 当前只验证Windows/UCRT64构建；未完成MSVC、不同GPU和长时间游戏的完整兼容矩阵。
