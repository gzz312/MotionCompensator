# 已知问题

**中文** | [English](en/KNOWN-ISSUES.md)

- 建议在无边框或窗口模式使用。独占全屏可能遮住外部浮层。请按目标游戏的规则使用外部浮层。
- 单调路面、雪地、天空、运动模糊、切镜和大面积前景遮挡会降低画面观测质量。动态点阵可能短暂停顿或在相邻区域表现不同。
- 当前兼容性验证以 Windows x64 和 UCRT64 为主。多显示器、不同 DPI 比例和完整键盘导航仍有待验证，设置窗口使用比例缩放。
- 多个版本同时运行时可能发生快捷键冲突。更新前请先退出旧版本，或在「通用设置」选择其他快捷键。
- 启用日志时，请从可写目录运行 EXE。程序会在 EXE 旁创建 logs 文件夹。

体验因游戏和个人而异。可先短时间使用静态或屏边点阵，再按自己的感受调整。
