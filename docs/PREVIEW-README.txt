MotionCompensator — 预览版
English: START-HERE.en.txt

先退出其他版本，再双击MotionCompensator.exe。优先使用游戏无边框/窗口模式。
自动连接已识别的前台游戏；未知游戏可在窗口列表手动选择并连接。

Ctrl+Alt+F8：切换点阵方案
Ctrl+Alt+F9：显示/隐藏
Ctrl+Alt+F10：停止采集

软件内“使用说明”介绍操作方法与设计参考；“许可与致谢”提供完整项目许可及第三方声明。
日志默认关闭，需要时勾选“日志”，复现后取消；不自动上传。

允许免费使用和分享，允许注明出处后商业集成；禁止独立售卖、换皮售卖和单独收费解锁。
完整条款见LICENSE.txt或程序内“许可与致谢”，中文正文为准；第三方许可独立保留。
项目与版本下载：https://github.com/gzz312/MotionCompensator/releases
已知限制见KNOWN-ISSUES.md。体验因人和游戏而异，出现不适时请停止使用。

EXE内置所需非系统依赖，系统仍需提供Windows图形组件。无需安装OpenCV、编译器或额外程序DLL。

界面：顶部连接游戏，左侧预览；右侧切换“点阵 / 准星”。点阵页按方案、外观和运动分组，超出区域时可滚动。日志与调试显示位于底部。
