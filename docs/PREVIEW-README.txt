MotionCompensator 0.2.0-preview.10
English: START-HERE.en.txt

解压后运行 MotionCompensator.exe。在游戏中优先使用无边框或窗口模式。
在「总览」刷新窗口列表，选择游戏并点击「登记并连接」。开启「自动连接已登记游戏」后，下次切回已登记的游戏时程序会重新连接。
在「视觉效果」选择静态点阵、屏边点阵、分区点阵或网格点阵，也可以单独设置中央准星。切回游戏即可观察浮层。
默认 Ctrl+Alt+F8 切换点阵，Ctrl+Alt+F9 显示或隐藏浮层，Ctrl+Alt+F10 停止采集和自动连接。可在「通用设置」修改快捷键。
在「运行诊断」启用日志后可记录复现过程，文件位于 EXE 旁的 logs 目录。

软件内「使用说明」介绍设置和点阵选择。「许可与致谢」提供项目许可、设计来源和第三方声明。
已知问题见 KNOWN-ISSUES.md，发布说明见 RELEASE-PREVIEW.md。
