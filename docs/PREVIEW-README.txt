MotionCompensator 0.1.0-preview.1 — 预览测试版
English: START-HERE.en.txt

先退出其他版本，再双击MotionCompensator.exe。优先使用游戏无边框/窗口模式。
自动连接已识别的前台游戏；未知游戏可在窗口列表手动选择并连接。

Ctrl+Alt+F8：切换点阵方案
Ctrl+Alt+F9：显示/隐藏
Ctrl+Alt+F10：停止采集

软件内“使用说明”含操作、设计参考与致谢；“许可与致谢”含项目许可状态及第三方完整文本。
日志默认关闭，需要时勾选“日志”，复现后取消；不自动上传。

允许免费使用和分享，允许注明出处后商业集成；禁止独立售卖、换皮售卖和单独收费解锁。
完整条款见LICENSE.txt或程序内“许可与致谢”，中文正文为准；第三方许可独立保留。
发布状态以GitHub仓库及Releases页面的实际内容为准。
已知限制见KNOWN-ISSUES.md；缓解效果需个人对照，出现不适就停止使用。

EXE内置所需非系统依赖，系统仍需提供Windows图形组件。无需安装OpenCV、编译器或额外程序DLL。
