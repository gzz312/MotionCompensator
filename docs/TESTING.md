# 测试与反馈

**中文** | [English](en/TESTING.md)

## 软件自身检查

`build.ps1`编译后执行CTest。检查覆盖设置兼容性、输入/光流管线、点阵周期与反向连续性、预览、主题控件、日志轮转、说明文档和资源打包；不能据此宣称游戏疗效或全部环境无闪烁。

构建目录的`desktop_smoke.exe`在真实Windows桌面依次运行静态、分区和屏边的软件自采集，约20秒，无游戏输入。它显式启用诊断日志，结果在同目录`desktop-smoke-results.txt`及`logs/`。普通启动仍默认关闭日志。

`MotionCompensator.exe --smoke-test`为单次约6秒的自采集。该检查需要可用的交互式Windows桌面；受限或非交互环境可能无法完成采集。

## 界面回归

1. 浅色、深色、跟随系统各切换；检查下拉、滑块、按钮、说明标题及滚动区。
2. 分区→屏边→静态→分区轮换，特别看背景适配下拉框是否闪白、各方案参数是否保持。
3. 最小化还原、拖动实时缩放、打开/滚动/关闭说明，检查漏画、持续残影与白边。
4. 确认“许可与致谢”包含完整项目许可、设计参考/视频和第三方许可。
5. 日志默认关闭；勾选后创建，取消后文件停止增长；目录不可写时提示并保持程序可用。
6. 软件主题不改变游戏点阵/准星颜色；测试后恢复原设置。

## 游戏内体验对照

优先在PAYDAY 2熟悉的单人场景测试。固定分辨率、FOV、帧率限制和输入灵敏度，比较工具关闭、工具运行但隐藏、静态点阵、分区点阵、屏边点阵。

短时比较同一路线，记录是否分心、遮挡、点阵连续性、主观不适0–10和开始不适的时间。出现不适就结束，不强撑；恢复后再决定是否继续。不要把短时主观改善当作普遍疗效或医学结论。

## 反馈模板

- 软件版本、Windows版本、显示器分辨率/缩放、多屏情况。
- 游戏及版本、窗口模式、复现步骤、频率、预期和实际行为。
- 点阵方案、关键视觉参数、输入设备。
- 可选：复现时手动开启的必要日志片段；分享前检查目标进程名和其他本地信息。

程序显示的采集/分析/提交FPS不是游戏帧率；CPU提交耗时不是GPU完成或屏幕呈现延迟。尚未测量的指标应标记为N/A。
