# 开发过程摘要

本文件保留适合源码审阅的流程记录；机器原始日志、旧版本EXE和完整历史验证文件仍在本地，未删除，不进入源码导出包。旧版HISTORY/BUILD/TESTING已在本地基线备份中保留。

- 初始阶段：Win32窗口选择、WGC采集、Direct2D/DirectComposition外部透明浮层。禁止Hook、注入与进程内存读取。
- 动态阶段：键鼠/手柄只读观察、灰度光流与输入预测融合，持续分区滚动；按用户要求不自动切成静态。
- 空间与表现：交错布局、双行周期、中心留空、屏边渐隐及固定邻点大小差异；反向只改变积分方向。
- 视觉适配：固定4×4静态点，左右外列柔边；灰度亮度采样、同色相明暗及双层描边。
- 可观测性：统一调试可视化，手动日志开关、容量轮转、状态与悬停提示。
- UI阶段：圆角控件、中英切换、浅深主题；多轮修复不等于证明所有环境无闪烁，相关已知边界保留。
- 0.16.1：背景适配/屏边选项复用，暂停原生组合框数据更新时的直接绘制。
- 本地预览收尾：版本与资源统一、构建入口去除本机固定路径、内置设计参考和许可状态、补齐静态运行库声明、修复静态中央留空约束、筛选公开文件。

## 验证原则

代码检查、软件自采集和用户真实游戏体验分开记录。用户负责游戏主观体验，程序自动检查只证明其覆盖的工程行为。已测试、尚未测试、未来功能不能混写。
